# CardBord
vr 체험용 — 스마트폰 카드보드·PC 브라우저·VR 헤드셋에서 바로 열리는 웹 VR 체험

## 체험 장면 3개
| 장면 | 내용 |
|---|---|
| 우주 전망대 | 별 3,000개, 고리 달린 행성, 전망 데크 |
| 숲 속 산책 | 나무 숲·안개, 이동 지점을 따라 걷기 |
| 스마트 팩토리 견학 | 움직이는 컨베이어와 로봇팔, 공정 설명 |

장면은 모두 기본 도형으로 그려서 외부 3D 모델·이미지 파일이 없습니다.

## 조작: 응시(gaze) 선택
화면 가운데 점을 빛나는 구슬에 맞추고 **1.5초** 바라보면(시간은 설정에서 변경) 실행됩니다. 진행 고리가 차오르며 남은 시간을 보여줍니다.
- 🔵 파란 구슬: 그 위치로 이동
- 🟡 노란 구슬: 설명 자막 표시
- 🟣 보라 구슬: 다른 장면으로 이동

## 보기 방식
| 방식 | 대상 | 설명 |
|---|---|---|
| 화면으로 보기 | PC·폰 | 마우스·손가락 드래그로 둘러보기 |
| 폰 움직여 보기 | 폰 | 자이로(기기 방향 센서)로 둘러보기 |
| 카드보드 | 폰 + 카드보드 | 좌우 분할 입체 화면, 전체 화면·가로 고정 |
| VR 헤드셋 | WebXR 지원 기기 | 지원하는 기기에서만 선택지가 나타남 |

센서가 없거나 권한이 거부되면 자동으로 드래그 방식으로 바뀌고 안내 자막을 띄웁니다. 아이폰은 시작할 때 동작·방향 권한을 묻습니다.

**카드보드 설정**: 눈 사이 거리(50~80mm), 시야각(60~100°), 응시 선택 시간(0.5~4초). 브라우저에 저장됩니다.

## 실행
three.js를 모듈로 불러오므로 **웹 서버로 열어야** 합니다 (파일 더블클릭은 브라우저 보안 정책으로 동작하지 않음).
```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000
```
폰에서 자이로·카드보드를 쓰려면 **HTTPS**가 필요합니다. GitHub Pages(Settings → Pages → main 브랜치)로 배포하면 바로 폰에서 열 수 있습니다.

## 개인정보
카메라·위치·마이크를 쓰지 않고 서버로 아무것도 보내지 않습니다. 설정값만 브라우저 localStorage에 저장합니다.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 메뉴 화면 |
| `app.js` | three.js 장면·렌더링·입력·카드보드 분할 화면·WebXR |
| `vr-core.js` | 기기 방향→카메라 회전 계산, 응시 타이머, 설정 범위 검사, 장면 데이터 (three.js 없이 테스트 가능) |
| `vr-core.test.mjs` | 단위 테스트 — `node --test` |

## 검증
- 단위 테스트 9개 통과: 폰을 세우면 정면·눕히면 아래·왼쪽으로 돌리면 왼쪽을 보는지, 가로 화면 보정, 쿼터니언 정규화, 드래그 상하 제한, 응시 1회 실행·초기화, 설정 범위, 장면 데이터 무결성
- Chromium(WebGL) 자동 점검 14항목: 장면 시작, 설명·이동·장면 전환 핫스팟, 드래그, 메뉴 복귀, 설정 유지, 카드보드 분할 화면, 센서 없을 때 안내, 모바일 메뉴, 콘솔 오류 없음
- **미검증**: 실제 폰 자이로·카드보드 착용감, VR 헤드셋(WebXR) 실기기
